# Recooked

> **You are not cooked. We are going to cook.**

Recooked is een mobile-first receptenplatform dat Generatie Z inspireert om zelf gezond en lekker te koken, en dat te delen met anderen. Gemaakt in opdracht van de **GLR Food Freaks** (Grafisch Lyceum Rotterdam) als antwoord op de *ontkoking*: jongeren koken steeds minder zelf.

## Functies

- Zoeken op **ingrediënt** en filteren op **type gerecht**, bereidingstijd en moeilijkheid
- Overzichtspagina per categorie en detailpagina per recept
- Registreren en inloggen
- Leden kunnen eigen recepten **toevoegen, aanpassen en verwijderen**
- Admin panel voor het beheer van recepten, gebruikers en categorieën
- Recepten delen via WhatsApp of link

## Technieken

HTML · CSS · JavaScript · PHP · MySQL · Git & GitHub

## Installatie

1. Clone de repository naar de `htdocs`-map van XAMPP
2. Maak in phpMyAdmin de database `recooked` aan en importeer `database/recooked.sql`
3. Vul je databasegegevens in bij `config/config.php`
4. Open `http://localhost/recooked`

## Beveiliging

Gehashte wachtwoorden, prepared statements, ge-escapete output en rolcontrole aan de serverkant.
